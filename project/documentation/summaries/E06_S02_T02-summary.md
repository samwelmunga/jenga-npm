# E06_S02_T02 Summary — Epic / Story / Task Cards

Created four components in `src/components/board/`: `StatusBadge` maps status strings to CSS classes; `TaskCard` shows title, id, optional assignee, and badge; `StoryCard` renders its header and a list of `TaskCard`s; `EpicCard` renders its header and a list of `StoryCard`s. Each component is minimal and composable.
