# Epic: Multi-Platform Agent Config Parity

## Purpose
The project currently uses Claude-specific variables and hooks (e.g. `CLAUDE_PROJECT_DIR` in `settings.json`, Claude Code hook events like `WorktreeCreate`/`SessionEnd`). This epic makes the configuration layer truly agent-agnostic: Jenga introduces its own canonical env vars and config schema that both Claude and GitHub Copilot (and future agents) can use. Anything achievable via Claude Code integration should be equally achievable via Copilot CLI integration, and vice versa.

## Definition of Done
- [ ] Claude-specific env vars (e.g. `CLAUDE_PROJECT_DIR`) are replaced or aliased with Jenga canonical vars (e.g. `JENGA_PROJECT_DIR`) resolved at runtime
- [ ] A `copilot-instructions.md` (or equivalent Copilot config) is generated by `jenga init` alongside `settings.json`
- [ ] Hook scripts are platform-aware: they resolve the correct project dir regardless of which agent is running
- [ ] `jenga init` idempotently scaffolds config for both Claude and Copilot
- [ ] Documentation updated to reflect multi-platform support
