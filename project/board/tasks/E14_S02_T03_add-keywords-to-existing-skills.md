# Task: Add `keywords` and `examples` to all existing skills

## Description
For every existing skill in `skills/`, update the `SKILL.md` frontmatter to add at least 3 `keywords` and 2 `examples`. Keywords should be short phrases closely associated with the skill. Examples should be natural-language prompts that a user might type to invoke the skill.

## Prerequisites
- E14_S02_T01

## Acceptance Criteria
- [x] Every existing skill has at least 3 `keywords` and 2 `examples` in frontmatter
- [x] Keywords and examples are relevant and accurately describe the skill's purpose
- [x] No existing frontmatter fields are removed or broken by the update
